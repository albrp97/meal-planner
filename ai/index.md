# AI Workflows

This directory contains AIDD-style workflow prompts tailored to Smart Meal Planner. Use these as checklists when asking an AI agent to perform recurring work.

## Commands

- `commands/catalog-audit.md` — audit recipe quality, categories, prices, and visible catalog state.
- `commands/youtube-ingestion.md` — ingest and approve recipes from a YouTube channel.
- `commands/tui-change.md` — implement terminal UI behavior or visual changes safely.
