# Meal Planner Custom Skills

| Skill | Use when |
| --- | --- |
| `meal-planner-recipe-curation` | Adding, approving, hiding, categorizing, pricing, or auditing recipes. |
| `meal-planner-youtube-ingestion` | Discovering channels, fetching transcripts/descriptions, extracting candidates, or approving/discarding YouTube recipes. |
| `meal-planner-tui` | Changing the terminal UI, keyboard controls, display rows, colors, search, history, details, or shopping-list views. |
